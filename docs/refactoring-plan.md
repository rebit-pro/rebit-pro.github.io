# План рефакторинга проекта

## Текущее состояние

Проект находится в `\\wsl.localhost\Ubuntu\home\user\rebit-pro.github.io`.

Сейчас это Vue 3 + Vite + Vuetify одностраничный сайт без `vue-router`, без SSG/SSR, с секциями в `src/App.vue`, данными в `src/data/portfolio.ts`, SEO и Schema.org прямо в `index.html`.

`sitemap.xml` содержит только главную. Форма заявки отсутствует: сейчас есть Telegram, email и GitHub-контакты. Деплой через GitHub Pages уже настроен: `npm ci`, `npm run build`, публикация `dist`.

## Главный вывод

Проект нужно переводить из лендинга-портфолио в статический корпоративный сайт ReBit с роутами, контентными сущностями, отдельными SEO-страницами и управляемой микроразметкой.

Рефакторинг лучше делать итерационно: сначала архитектурный каркас, затем бренд и дизайн, затем расширение страниц услуг, кейсов и блога.

1. `vue-router` + генерация статических страниц.

## Первый практический шаг

Начать стоит не с полной перерисовки, а с архитектурного каркаса:

1. `src/config/site.ts`.
2. Новые `src/content/*` файлы.
3. `vue-router`.
4. Список маршрутов.
5. Генерация sitemap/meta.
6. Страницы услуг.

После этого можно спокойно переносить текущие секции в новый бренд ReBit и не ломать сайт крупным одномоментным изменением.
